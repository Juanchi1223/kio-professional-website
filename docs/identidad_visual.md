# KIO — Identidad visual
 
## Paleta
| Nombre | HEX | Uso sugerido |
|---|---|---|
| Terracota | `#9a3631` | Color de marca: acentos, palabras destacadas, CTAs, barra vertical |
| Gris | `#818080` | Textos secundarios, detalles |
| Negro | `#131312` | Titulares y texto principal |
| Blanco | `#ffffff` | Fondos |
 
## Tipografía
- **Familia: Nunito Sans** (Google Fonts, gratuita, apta web). Elegida el 15/11/2026.
- Titulares: Nunito Sans 800 (ExtraBold) / 700 (Bold)
- Subtítulos: Nunito Sans 600 (SemiBold)
- Texto: Nunito Sans 400 (Regular), interlineado ~1.5
- Por qué: sus curvas suaves combinan con las terminaciones redondeadas del isotipo y con el tono cercano y preventivo de la marca.
```html
<link rel="preconnect" href="https://fonts.googleapis.com">
<link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>
<link href="https://fonts.googleapis.com/css2?family=Nunito+Sans:opsz,wght@6..12,400;6..12,600;6..12,700;6..12,800&display=swap" rel="stylesheet">
```
```css
body { font-family: 'Nunito Sans', system-ui, sans-serif; }
```
